# Sistema de Gestión de Inventario

## Descripción

Este proyecto consiste en un sistema de gestión de inventario desarrollado en Python para una tienda.

El programa utiliza una clase llamada `InventarioTienda`, encargada de administrar los productos y ejecutar un menú interactivo.

El sistema permite:

- Agregar productos con nombre, precio y cantidad.
- Vender productos y disminuir su existencia.
- Mostrar todos los productos del inventario.
- Consultar el producto más caro.
- Mostrar el número de productos diferentes.
- Calcular el valor total del inventario.
- Consultar productos con bajo stock.
- Validar los datos ingresados.
- Manejar errores mediante excepciones.

## Requisitos

Para ejecutar el proyecto se necesita:

- Python 3 instalado.
- Un editor de código, como Visual Studio Code.
- Una terminal o consola.

El proyecto no requiere instalar librerías adicionales.
